# Tint Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Tint page grades picture clips with corrections stored once as a node graph and shown as layers (Baby Seal) or nodes (Leader Seal), with professional tools, honest scopes, and the same result in preview and export.

**Architecture:** The grade is document data in `project` (`Clip.grade`, like `Clip.sound`). The `preview` owns one WebGL2 runner per engine (`preview/gpu/`) and two points, `pictureFilters` and `frameFilters`, that hand it shader passes; it also fixes WebKitGTK's squeezed video levels in that runner. The `tint` feature owns the graph logic, the color math (a TypeScript reference and GLSL), every `tint.*` command and `tint_*` tool, and the page in layout D. Export needs nothing new: `createRenderer` runs the same filters.

**Tech Stack:** TypeScript (strict), React 19, Zustand + Immer, Zod, WebGL2 (GLSL ES 3.00), Tailwind v4 tokens, Tauri 2 (Rust, for `.cube` reading), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-03-tint-page-design.md` · **Mockup:** `docs/prototype/designs/tint-d-studio.html`

## Global Constraints

- Every rule in `CLAUDE.md` holds. Read the `README.md` of each folder you touch first, and update it in the same task.
- Work on the current branch (`master`). Commits have **no** `Co-Authored-By` line.
- A task is done when `pnpm typecheck`, `pnpm lint` and `pnpm test` pass; Rust tasks add `cd src-tauri && cargo clippy --all-targets -- -D warnings && cargo test`.
- Untouched is unchanged: a clip with no `grade` stores nothing new, and a project with no grade data saves in the current file version.
- A value equal to its default is never stored (`minimize` like `soundOf`/`writeSpeed`).
- No module creates a WebGL context except `preview/gpu/`. No module but `preview` touches `<video>`.
- Grades apply to media clips with a picture (video, image) and composition clips only. Never text, sticker, solid.
- Output is Rec.709 gamma 2.4, display-referred, 8-bit sources (spec "Decisions after review").
- If WebGL2 is unavailable, Tint shows an empty state and an export of a graded clip fails with `tint.unavailable`.
- Ship only working controls. No Detail tab, no Grain, no shapes, no tracking, no agent box, no Warper "Color · brightness" mode.
- Names: only those in the spec's "Names" section. Never DaVinci, Resolve, Blackmagic, Fusion, Fairlight, Lumetri, Magic Mask, Color Warper, Kodak, Fuji, X-Rite, ColorChecker.
- A gesture sends one command on release (rule 15); live values go through `tint`'s live store, never history.
- No React state on per-frame paths: scopes, wipe, wheel pucks, sliders while dragging (rule 24).
- Tests kept at the end (rule 3, memory "prune tests"): `project/logic/grade.test.ts`, `tint/logic/stack.test.ts`, `tint/tint.commands.test.ts`, and the grade case added to `timeline.commands.test.ts`. Any other test written while building is deleted in the stage's wrap task.

## Review Focus

1. **A graph an undo leaves broken** (agent removes a node, user undoes an older step that rewired it): the project refuses the undo. Pinned in Task 4 (`projectPolicy.validate` case) and Task 8 (undo test).
2. **Splitting a graded, keyed clip**: both halves keep the grade and the `grade.*` tracks, and the right half's keys sit where the cut is. Pinned in Task 5.
3. **A clip whose grade references a missing LUT or shot group** (file moved, group deleted by an agent): preview draws without it and warns once; export fails naming it. Pinned in Task 4 (`settle` drops a deleted group) and Task 22 (missing LUT).
4. **Export of an ungraded project after this work**: pixels identical to before. Pinned in Task 2's check step and Task 13's wrap.
5. **Lost WebGL context mid-playback** (GPU reset, laptop sleep): next frame recreates it; if that fails, the preview tells the user once and draws ungraded, and an export fails. Pinned in Task 2 (runner test page step) and Task 3 (filter error path).
