# Auto mask Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Click anything on a media clip, see its mask at once, track it through the clip with SAM 2.1 (bundled, offline, Faster/Better), refine it, fix only the stretch around a correction, find problem frames, and convert it to a path mask.

**Architecture:** A new mask kind `auto` (data in `project`) draws a grayscale matte file (a `media` derived file) by the clip's source time. A feature module `automask` owns the commands, the MCP tools, the UI and a follower that wants segment and matte names derived from the document. `src-tauri/src/automask/` runs SAM through ONNX Runtime in its own queue, keeps raw per-frame results per segment, and refines them into the matte. `preview` finds mattes through a new point `maskSources`, so `preview` and `export` never know `automask`.

**Tech Stack:** TypeScript (strict), React 19, Zustand, Immer, Zod, Vitest; Rust (edition 2024, Tauri 2, tokio), `ort` (ONNX Runtime), FFmpeg (system binary), Git LFS for the models.

**Spec:** `docs/superpowers/specs/2026-11-21-auto-mask-design.md` (read it whole before any task). Prototype: `docs/prototype/designs/auto-mask.html`.

## Global Constraints

- Rules in `CLAUDE.md` apply to every task. The most relevant: imports only through `@/core`, `@/ui`, `@/modules/<name>`; every interface/type in a `.types.ts`; dotted file names; files under ~200 lines; `<name>.module.ts` is wiring only; no module-level singletons; every `index.ts` export, command and MCP tool has TSDoc; failures reach the user via command results or `notify`.
- A task is done when `pnpm typecheck`, `pnpm lint`, `pnpm test` pass; Rust tasks also pass `cd src-tauri && cargo clippy --all-targets -- -D warnings && cargo test`. Rust: no `unwrap`, `expect` or `panic` (denied lints).
- Times are integer microseconds (`Micros`). Click positions in commands are output px; stored prompts are 0..1 of the source picture.
- Values fixed by the spec: refine defaults consistency 30, cleanup 20, edge 0 (each 0..100); `WEAK_IOU` 0.7; `AREA_JUMP` 0.35; Consistency up to ±3 frames at 100; Clean up up to 0.5% of the picture area at 100; raw results at most 1024 on the long side; matte at source size capped at 1920 on the long side, `yuv420p`, `-dn -write_tmcd 0 -map_metadata -1`; matte luma remap 16..235 → 0..1 clamped; overlay tint 45%; Convert Points 8..64 default 24, Smoothness 0.5..4 px default 1.5.
- Models: SAM 2.1 tiny = `faster`, SAM 2.1 small = `better`, bundled under `src-tauri/resources/automask/` via Git LFS with `LICENSE-SAM2` and ONNX Runtime's license. Device: Auto = DirectML on Windows else CPU; CPU only on Linux.
- A shortcut with a known limit gets a comment: `shortcut: <the limit>, <when to upgrade>`.
- Commits: conventional (`feat(automask): …`), no Co-Authored-By or Claude attribution lines.
- No legacy support: old projects need no migration.

## Review Focus

1. **A reversed or sped-up clip:** the matte must be read at the clip's source time, not the timeline's. Pinned by `matteTimeAt` tests (Task 8).
2. **A flipped, scaled or rotated clip:** a click must land on the same spot of the source picture, and a click off the picture must fail with `automask.off_picture`. Pinned by `toSourcePoint` tests (Task 6).
3. **A relinked or replaced file:** a segment or matte name must change with the file's revision, or a stale result is reused. Pinned in `segments.test.ts` (Task 6).
4. **Undo of a click or a track while tracking:** the job for a name nothing wants any more is cancelled, and redo finds the earlier names. Pinned by the `wanted` tests (Task 6); the queue follows `wanted`.
5. **A still image, an animated image, a sound clip:** Track must be refused on a still (`automask.not_still`), and `add` must be refused on an animated image or a non-media clip (`automask.not_media`). Pinned in `automask.commands.test.ts` (Task 7).
