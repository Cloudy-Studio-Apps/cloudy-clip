# Stickers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Stickers tab with packs, topics, search, optional variations and animated stickers, plus a public point for plugin packs and styles.

**Architecture:** A new `feature` module `sticker`. Packs contribute to a `stickerPacks` point, styles to `stickerStyles`; a library resolves them. One `sticker` element stores references (`pack`, `sticker`, `variation`) and draws through an art cache. `element` and `preview` gain two generic additions: the time inside the clip, and a way for a picture to say it isn't ready.

**Tech Stack:** TypeScript, React 19, Zustand, Zod, Tailwind v4, Vitest, `lottie-web` 5.13 (MIT).

**Spec:** `docs/superpowers/specs/2026-10-30-stickers-design.md`

## Global Constraints

- All rules in `CLAUDE.md` apply. A task is done when `pnpm typecheck`, `pnpm lint` and `pnpm test` pass.
- Rule 3 limits tests to the plan's list. Add none beyond it.
- Rule 12: no module-level state. The element is built by a factory in `setup`.
- Rule 29: every `interface`/`type` goes in `sticker.types.ts`.
- Rule 31: TSDoc on every export of `index.ts`, every command, every tool.
- Commit messages carry no `Co-Authored-By` line (the user's standing rule).
- Work on a branch `feat/stickers`.
- Natural size: `STICKER_SHARE = 0.3` of the format's short side. New sticker length: 3 s (the `addElement` default).
- Recents: `localStorage` key `cloudy-clip.stickers.recent`, 12 entries, failures ignored (as `inspector.recents.store.ts`).
- Fluent source: `microsoft/fluentui-emoji` at `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`, group `Smileys & Emotion`, Flat style only.
- Editing colors: white `#ffffff`, black `#111111`, red `#e5484d`, yellow `#ffd60a`, blue `#2f8fff`, green `#30c46c`; default white.
- Pack order: `seal` 10, `editing` 20, `fluent` 30.
- Lottie is imported dynamically from `lottie-web/build/player/lottie_light_canvas`, never at module top level (it needs a DOM, and tests run in node).

## Review Focus

1. Art that fails to load, or a clip whose pack was removed: the preview keeps painting with a placeholder and never waits forever (Task 3 test).
2. A clip on screen before its pack's list has loaded: the frame waits, then the sticker appears with no user action (Task 3 test).
3. `preview_capture_frame` on a frame with a sticker: it returns a picture, never a stale frame, and SVG art doesn't taint the canvas (Task 8 check).
4. Two clips of one animated sticker at different times, including under a transition: each shows its own frame (Task 8 check, one player seeked before each draw).
5. Typing fast in search while a list loads: the newest query wins, with an empty state for no results (Task 2 test for the search, Task 6 check for the race).

```ts
type StickerVariation = Record<string, string>;
interface StickerArt {

  url: string;
}
interface StickerTopic {
  id: string;
  label: string;
}
interface StickerOption {
  id: string;
  label: string;
  swatch?: string;
}
interface StickerAxis {
  id: string;
  label: string;
  options: StickerOption[];
  default: string;
}
interface StickerDefinition {
  id: string;
  label: string;
  keywords?: string[];
  topics?: string[];
  aspect?: number; // width / height, 1 by default
  variations?: string[]; // axis ids this sticker uses
  thumbnail?: string; // tile image; required in practice for lottie art
  art(variation: StickerVariation): StickerArt;
}
interface StickerPackDefinition {
  id: string;
  name: string;
  order: number;
  credit?: string;
  cover?: string[];
  topics?: StickerTopic[];
  variations?: StickerAxis[];
  stickers: readonly StickerDefinition[] | (() => Promise<readonly StickerDefinition[]>);
}
interface StickerStyleDefinition {
  pack: string;
  axis: string;
  option: StickerOption;
  art(sticker: StickerDefinition, variation: StickerVariation): StickerArt;
}
interface StickerHit {
  pack: string;
  sticker: StickerDefinition;
}
interface StickerQuery {
  text?: string;
  topic?: string;
  pack?: string;
  limit?: number;
}
interface StickerRecent {
  pack: string;
  sticker: string;
}
interface StickerApi {
  packs(): StickerPackDefinition[]; // by order
  topics(): StickerTopic[]; // merged by id
  load(pack: string): Promise<readonly StickerDefinition[]>; // cached; [] for an unknown pack
  find(pack: string, sticker: string): StickerDefinition | undefined; // sync, loaded lists only
  isLoaded(pack: string): boolean;
  axes(pack: string, sticker: string): StickerAxis[]; // merged with styles, used axes only
  artOf(pack: string, sticker: string, variation: StickerVariation): StickerArt | undefined;
  search(query: StickerQuery): Promise<StickerHit[]>;
  onLoaded(listener: () => void): () => void;
  recents: { store: StoreApi<{ recents: StickerRecent[] }>; push(recent: StickerRecent): void };
}
```
