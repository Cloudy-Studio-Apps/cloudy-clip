# path

Motion paths: a curve drawn on a composition's frame that picture clips travel along over time. One path can carry any number of clips (three birds on one arc); reshaping it moves them all. A clip's Progress (keyable, 0 → 100 %) says where on the path it is, by distance, so it moves at an even speed and eases only as its Progress keys do. While following, the clip's Position is an offset from the path, so followers can sit side by side, and Orient along path adds the path's direction to its rotation. After Effects' motion path / GSAP's MotionPath, shared like Blender's Follow Path.

- **Tier:** feature
- **Requires:** `project` (the paths, `followedClip`, `bakeFollow`), `element` (`sharedGroups`), `keyframe` (`setKey`, for the Progress keys), `preview` (the actor's playhead, as the default `at`), `inspector` (`propertyControls`, `FieldRow`), `media` (`librarySections`), `timeline` (the clip selection)
- **Contributes:** shared group `follow` (`sharedGroups`, `path.group.ts`), which the picture elements opt into with `supports.follow` (media, text, sticker, solid, composition); command control `path-picker` (`propertyControls`); Library section `path.section` (`librarySections`); overlays `path.overlay` and `path.drawing` (`previewOverlays`)
- **Points it owns:** —
- **API** (`useModule(pathRef)`): `ui` (`PathUiState`, per kernel, never in history: `selectedPathId`, the path shown on the canvas; `selectedPoint`; `drawing`, `{ mode: "freehand" | "pen", attach }` while a path is being drawn)
- **Files:**
  - `path.group.ts`: `followGroup` at `clip.follow` (`ClipFollow`: `pathId`, `progress`, `orient`; default `NO_FOLLOW`), only on video tracks. `pathId` is `hidden` and `readOnly`, so `element.setProps` refuses it (`element.read_only`): a clip joins or leaves a path only through `path.attach` / `path.detach`, which key Progress and bake, so no route makes it jump. `progress` is a number from −10 to 10 (slider 0–100 %), keyable as `follow.progress`; `orient` a boolean.
  - `path.commands.ts`: create, update, remove; `requirePath`. `path.follow.commands.ts`: attach, detach. `path.schema.ts`: `pathPoints` (two or more, handles default to 0).
  - `path.mcp.ts`: the tools, and `path_list`. `path.store.ts`: `createPathUi()`.
  - `ui/PathPicker.tsx`: the Follow path section's Path row (the `path-picker` control on `path.attach`): None, the clip's composition's paths, Draw new path…; Mixed when the selected clips differ. A path runs `path.attach`; None runs `path.detach` at the playhead; Draw new path sets `ui.drawing` with the clips to attach.
  - `ui/PathsSection.tsx`, `ui/PathRow.tsx`: the Library's Paths of the open composition, each with its follower count. New starts drawing (nothing attached); a click selects a path (again deselects); a double-click renames it (`path.update`, Enter or blur; Escape cancels); the bin deletes it (`path.remove` at the playhead).
  - `ui/PathOverlay.tsx`, `ui/path.edit.gesture.ts`, `ui/path.paint.ts`, `logic/edit.ts`: the path on the canvas. Shown when it is picked in the Library (`ui.selectedPathId`), else when exactly one selected clip follows it; hidden while drawing. An SVG in the frame's own space (`viewBox` centered, so points need no offset): the line (`stroke-primary`, `vector-effect: non-scaling-stroke`) over a wide transparent stroke that takes the double-click, square points, and the selected point's two handles (round, on stems). DOM only, never in a capture or export. A press on a point selects it; dragging a point (its handles travel with it) or a handle redraws the overlay in the DOM (`paintPath`, no React renders) and release sends one `path.update`; a handle keeps the other in line at its own length (`movePart`) unless Alt is held; Escape cancels; a failure is a toast. Double-click within 24 output px of the line adds a point there without changing the shape (`nearestOnPath`, `insertPoint`: de Casteljau). Delete or Backspace (capture phase, not in text fields) removes the selected point, never below two (`removePoint`). `pathData` is the SVG `d`.
  - `ui/PathDrawing.tsx`, `ui/draw.gesture.ts`, `logic/fit.ts`: drawing a new path while `ui.drawing` is set (Library New, or the picker's Draw new path…). It covers the frame (crosshair) with a small bar: Freehand / Pen, Done (pen), Cancel. **Freehand** (default): press, draw, release; the line follows in the DOM, and the stroke is fitted into a few smooth points (`fitStroke`, Schneider's least-squares Bézier fitting, within 4 screen px, splitting where it can't, handles in line at each split). **Pen:** a click adds a corner, a click-drag pulls its handles (mirrored), a click within 8 screen px of the first point closes the path and finishes; Enter, a double-click or Done finishes (points a double-click stacks are merged); Escape or Cancel stops without a path. Finishing with two or more points sends one `path.create` with the clips to attach, then selects the new path; a failure is a toast.
- **Data:** paths live in the document (`ProjectState.paths`, `project` declares and validates them, see its README), one record each, so each undoes on its own. Where a follower is placed is `project`'s `followedClip`.
- **Invariants:** a path has two or more points and belongs to one composition; a clip follows only a path of its own composition (the document refuses anything else, so an undo that would leave a follower on a deleted path is refused). Leaving a path (detach, delete) never moves the clip at `at`: `bakeFollow` adds the path's shift there to the position and rotation and their keys. Every command is one undo step; `path.create` with `attach` runs `path.attach` inside it.
- **Not yet:** a path that moves or animates; scrubbing Progress by dragging along the path; drawing the path into the picture.

| Command       | MCP tool      | Notes                                                                                                                                                                                                                                                  |
| ------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `path.create` | `path_create` | Points in output px from the frame's center with handle offsets; `closed`; `name` (default `Path N`); `compositionId` (default your open one); `attach` (clips that follow it, same step). `composition_not_found`. Returns `pathId`                   |
| `path.update` | `path_update` | Points (whole), name or closed; at least one. Followers move with it. `not_found`, `nothing`                                                                                                                                                           |
| `path.remove` | `path_remove` | Many ids, all or none. Followers are baked at `at` (default your playhead). `not_found`                                                                                                                                                                |
| `path.attach` | `path_attach` | Sets `follow`, zeroes the static X/Y (X/Y keys stay as offsets), keys Progress 0 at the clip's first frame and 1 at its last unless it has Progress keys already. `clip_not_found`, `not_picture`, `not_found`, `other_composition`. Returns `clipIds` |
| `path.detach` | `path_detach` | Bakes at `at` (default your playhead); clips that follow nothing are skipped. `clip_not_found`                                                                                                                                                         |
| (read)        | `path_list`   | `{ id, name, closed, points, followers }` of a composition (your open one by default)                                                                                                                                                                  |
