# tint

The Tint page, a tab between Edit and Sound, where colors are graded: corrections stored once as a graph, shown as layers (**Baby Seal**) or as nodes (**Leader Seal**), with Basics, wheels, curves, Color mix, Warper, Creative, limits, LUTs, Match and the RGB mixer, scopes beside them and the clips below. **The frame, the layer list, Basics, the wheels (Primary, Log, Bars, Zones), the curves, Color mix, the Warper, Creative, Limit and the RGB mixer are real; LUT and color and Match are still demo data**: the viewer (the preview's own stage, so it plays), the clip strip, the current clip and the seal switch read the open project; the layer list (Baby Seal) reads and edits the current clip's real grade; Basics, the wheels, Curves, Color mix, the Warper, Creative, Limit and the RGB mixer edit the selected layer (else the first correction; with none yet, the first edit adds one); the node graph (Leader Seal) reads and edits the same grade; the other tools are still drawn from demo data (`ui/demo/`) and edit nothing yet. A clip's saved grade already draws (every value of a correction but its LUT: Basics, all the wheels, the curves, Color mix, the warper, skin pull, the mixer, Creative and its limit by color and brightness or a shared key; and side-by-side, stacked and per-channel groups) in the preview, captures and export through the `tint.grade` filter. The design is `docs/superpowers/specs/2026-11-03-tint-page-design.md`, the plan `docs/superpowers/plans/2026-11-03-tint.md`, the picture `docs/prototype/designs/tint-d-studio.html`.

- **Tier:** feature
- **Requires:** `project` (grade types and helpers, the strip), `preview` (the picture filter, `redraw`, playback, `gpuAvailable`, `PreviewStage`), `timeline` (the selection), `media` (probes for the strip's cards)
- **Contributes:** picture filter `tint.grade` (`pictureFilters`, order 100, `tint.filter.ts`): applies to a clip with a grade that `canGrade`; its passes are `gradePasses(clip.grade, live, textures, aspect)` (`aspect` from the filter's `size`, for the vignette), so a grade shows in the preview, captures and export; live values are laid over it only when `target` is `"preview"`, so a capture or an export draws the saved document even mid-drag; so is Limit's Show (`view.showPicked`, passed as `gradePasses`' `show`), which never reaches a capture or an export. One per kernel (`createTintFilter(live, view)`), since it reads that kernel's live values and view (`redrawOnShow` redraws the preview when `showPicked` changes), with its own lookup tables (`createGradeTextures`); page `tint.page` (`TINT_PAGE`; `appPages`, icon `Palette`); top bar item `tint.sealSwitch` (`topBarItems`, right: Baby Seal | Leader Seal; `topBarItems` has no page filter, so `SealSwitch` reads `pagesRef` and renders nothing unless the Tint page is open); keybindings `tint.previousClip` and `tint.nextClip` (Up, Down; only on the Tint page; `tint.keys.ts`); the page has `keepsPlayback`, so Space plays and pauses on it
- **Commands** (all undoable; a `target` is `{ clipId }`, `{ groupId }` (a shot group) or `{ compositionId }`; each reads the grade, edits a copy with `logic/stack*.ts`, runs `minimizeGrade` and `validateGrade`, then writes once):
  - `tint.addCorrection` (`tint_add_correction`): `{ target, at?, values?, limit?, name? }` adds a layer (default: the bottom of the stack) and returns `{ nodeId }`.
  - `tint.setCorrection` (`tint_set_correction`): `{ target, nodeId, patch: { values?, limit? (null removes), opacity?, on?, name? } }`; each given value field replaces that field whole. A `limit.from` written by the patch (any limit on `tint.addCorrection`; other edits of a node keep its stored key unchecked, `validateGrade` still guarding the graph) is checked by `checkSharedKey` (`tint.guards.ts`, `logic/keys.ts` `keyProblem`) before anything is written: it must name a key join or a correction whose limit limits something (its own pick or a shared one), else `tint.key_not_limited`, and not this one or one drawn from it, else `tint.key_cycle`.
  - `tint.setCorrections` (`tint_set_corrections`): `{ target, nodeIds, patch: { on?, opacity? } }`; turns several corrections on or off or fades them in one undo step, all or nothing (one animated field, or a node that is no correction, refuses the lot: `tint.animated`, `tint.node_not_found`). A sealed card's eye and fade use it.
  - `tint.group` (`tint_group`, `tint.group.commands.ts`): `{ target, nodeIds, kind: "parallel" | "layer" | "channels" }` puts items that follow one another in one list into a group (`logic/stack.group.ts` `groupLayers`; side by side and stacked need two or more, per channel one to three, into the red, green, blue branches) and returns `{ joinId }`; `tint.cant_group` otherwise.
  - `tint.ungroup` (`tint_ungroup`): `{ target, joinId }` takes a group apart (`ungroup`: the branches' items in a row, top branch first), and the join's and split's key tracks go; `tint.not_a_group` when `joinId` isn't a group the stack shows.
  - `tint.setGroup` (`tint_set_group`): `{ target, joinId, patch: { opacity?, on?, blends? } }` for a side-by-side or stacked group (`blends` only stacked, one per branch); `tint.not_a_group` for a per-channel group or blends on side by side; `tint.animated` for a keyed field. Writes nothing when the grade comes out the same.
  - `tint.removeNodes` (`tint_remove_nodes`): `{ target, nodeIds }`; consumers read the removed node's input, and its `grade.nodes.<id>.*` key tracks go with it.
  - `tint.moveLayer` (`tint_move_layer`): `{ target, nodeId, to }`.
  - `tint.reset` (`tint_reset`): `{ target, tools?, nodeId?, fields? }`; with none of `tools`, `nodeId` and `fields` the whole grade (and every `grade.*` track) goes; with `tools` only the fields those tools own (`logic/tools.ts`, `TOOL_FIELDS`) are cleared, keys included; `nodeId` limits that to one correction, or to every correction inside a group when it is a group's join (`groupOf`) (all tools when none are given); `fields` names top-level value fields to clear beside the tools or alone, and a name that isn't a field of `DEFAULT_CORRECTION` fails with `tint.invalid_grade` before anything is written.
  - `tint.wire` (`tint_wire`, `tint.wire.commands.ts`): Leader Seal's free wiring, `{ target, set: { nodeId, input?, inputs?, r?, g?, b?, keys? }[], add?: { id, node }[] }`. `add` puts nodes in first (ids the caller's own, letters, digits and `_` only as `createId` makes them, else `tint.bad_id`, since a `.` would break a `grade.nodes.<id>.` track path; `tint.node_exists` for a taken one, `"source"` or `"out"`), then each `set` writes the wires of its node's kind (`input` a correction or split, or `nodeId: "out"` for the grade's result; `inputs` a side-by-side or stacked join, whose `blends` stay with their refs and new refs get normal; `r`, `g`, `b` a channel join; `keys` a key join); a field the kind doesn't have is `tint.cant_wire`. Every node id and ref is checked with `Object.hasOwn` (`tint.node_not_found`), a node that would read itself through pictures or keys is `tint.wire_cycle` (project's `gradeReads` from each new read), anything else `validateGrade` refuses is `tint.invalid_grade` (such as a picture ref naming a key join: it has a key, not a picture); then one write, one undo step, nothing when the grade comes out the same. Any valid shape goes: what Baby Seal can't show is sealed, and only that region (`parseStack` reads it again).
  - `tint.placeNodes` (`tint_place_nodes`: an agent lays out the graph as a user can): `{ target, pos: Record<nodeId, { x, y }> }` sets nodes' `pos` in graph units, one undo step, nothing written when no place changes; `tint.node_not_found` for a missing id. `logic/autolayout.ts` `autoLayout(grade)` places the nodes without one (one column per step from the source, the furthest read deciding; rows down each column in `topoOrder`, 150 × 100 units).
  - `tint.setInput` (`tint_set_input`, `tint.color.commands.ts`): `{ clipIds, input }` sets the camera color space (`InputColorSpace`, `INPUT_SPACES`) of clips in one undo step: every clip is read first (`tint.target_not_found`, `tint.not_gradeable`; a composition clip takes only `rec709`, its picture being Rec.709 already: `tint.input_not_for_composition`), then one `ctx.mutate` for all; a clip whose `input` is already the one asked is skipped; `rec709` is the default and is never stored (`minimizeGrade`), so a clip set back to it with no corrections is ungraded again. Nothing is written when no clip changes. `tint_get_grade` returns `input`; `tint_describe` lists the spaces and explains them.
  - Read tools: `tint_scopes` (`{ at?, compositionId? }`: captures the graded frame with `captureAt` at `at` (default the agent's playhead in its open composition; pass `at` with another composition; no seek, the time measured comes back as `time`) and measures it with `scopeStats`: r, g, b `{ min, max, mean }` 0 to 255, `clipped.low/high` shares 0 to 1 of pixels at or under 1% / at or over 99% luma, `histogram` 16 luma buckets as shares, `skinDistance` mean degrees from the 123 degree skin line weighted by saturation), `tint_get_grade` (`{ target }`: the layers, numbers, and nodes with full values) and `tint_describe` (fields and defaults, ranges, tools, color spaces, looks, LUTs).
  - Failures: `tint.target_not_found`, `tint.not_gradeable`, `tint.node_not_found`, `tint.invalid_grade` (the `validateGrade` message; nothing is written), `tint.sealed` (a place inside a sealed card or a move the stack can't show), `tint.animated` (a static write to a field that has keys; the key path comes later), `tint.key_not_limited`, `tint.key_cycle`, `tint.key_not_above`, `tint.cant_group`, `tint.not_a_group`, `tint.bad_id`, `tint.node_exists`, `tint.cant_wire`, `tint.wire_cycle`.
- **View commands** (not undoable, not saved, no MCP tools: they are the user's view; `tint.view.commands.ts`): `tint.setMode` (`baby` | `leader`), `tint.pin` (`{ clipId | null }`: makes a gradeable clip of the open composition the one being graded and seeks into it, to where it was last viewed, else its middle; fails with `tint.clip_not_found`), `tint.selectNode`, `tint.setTool`, `tint.setLevel`.
- **Current clip** (`tint.current.ts`, `followCurrent`, registered in `setup` with `onDispose`): the pinned clip until the playhead leaves it (or it is deleted, or another composition opens), else the gradeable clip (`canGrade`, not disabled) under the playhead on the topmost video track that isn't hidden. It follows the playhead without React; `TintApi.current()` and `onCurrent(fn)` read it, and `viewedAt(clipId)` is where the playhead last was inside a clip. Clicking a card in the strip runs `tint.pin`; Ctrl, Cmd or Shift click goes through `TimelineApi.selectClip(id, true)`, so that selection is shared with Edit and shows on the card.
- **Points it owns:** none yet (`tintLooks` comes with looks)

Colors outside Rec.709 clip at black at the end of the conversion; light over 1 is kept for the grade (on 8-bit fallback targets it clips at the first pass). The conversion's input range comes from the probe (`fullRange`); a file not probed yet reads as video range. The CPU and the GPU agree within one 8-bit step for every space and range alone; with a grade after it, a few values (16 in 384 000) of pixels converted far over white (1.8 to 8) and pushed hard by the grade differ by 2 to 4 steps, the half-float picture between passes (the check doc's Stage 5).
- **Bit depth:** grading (being built, see the plan) works on 8-bit pictures, in the preview and in export, which is what the app decodes today. TODO: support 10-bit and 16-bit sources (camera log footage), at least for export, so heavy grades don't band. See the design's "Decisions after review".
