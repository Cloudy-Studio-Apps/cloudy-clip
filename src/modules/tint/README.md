# tint

The Tint page, a tab between Edit and Sound, where colors are graded: corrections stored once as a graph, shown as layers (**Baby Seal**) or as nodes (**Leader Seal**), with Basics, wheels, curves, Color mix, Warper, Creative, limits, LUTs, Match and the RGB mixer, scopes beside them and the clips below. **The frame, the layer list, Basics and the primary wheels are real, the other tools are still demo data**: the viewer (the preview's own stage, so it plays), the clip strip, the current clip and the seal switch read the open project; the layer list (Baby Seal) reads and edits the current clip's real grade; Basics and the primary wheels (Primary mode only for now) edit the selected layer (else the first correction; with none yet, the first edit adds one); the node graph and the other tools are still drawn from demo data (`ui/demo/`) and edit nothing yet. A clip's saved grade already draws (Basics and the primary wheels) in the preview, captures and export through the `tint.grade` filter. The design is `docs/superpowers/specs/2026-11-03-tint-page-design.md`, the plan `docs/superpowers/plans/2026-11-03-tint.md`, the picture `docs/prototype/designs/tint-d-studio.html`.

- **Tier:** feature
- **Requires:** `project` (grade types and helpers, the strip), `preview` (the picture filter, `redraw`, playback, `gpuAvailable`, `PreviewStage`), `timeline` (the selection), `media` (probes for the strip's cards)
- **Contributes:** picture filter `tint.grade` (`pictureFilters`, order 100, `tint.filter.ts`): applies to a clip with a grade that `canGrade`; its passes are `gradePasses(clip.grade, live)`, so a grade shows in the preview, captures and export; live values are laid over it only when `target` is `"preview"`, so a capture or an export draws the saved document even mid-drag. One per kernel (`createTintFilter(live)`), since it reads that kernel's live values; page `tint.page` (`TINT_PAGE`; `appPages`, icon `Palette`); top bar item `tint.sealSwitch` (`topBarItems`, right: Baby Seal | Leader Seal; `topBarItems` has no page filter, so `SealSwitch` reads `pagesRef` and renders nothing unless the Tint page is open); keybindings `tint.previousClip` and `tint.nextClip` (Up, Down; only on the Tint page; `tint.keys.ts`); the page has `keepsPlayback`, so Space plays and pauses on it
- **Commands** (all undoable; a `target` is `{ clipId }`, `{ groupId }` (a shot group) or `{ compositionId }`; each reads the grade, edits a copy with `logic/stack*.ts`, runs `minimizeGrade` and `validateGrade`, then writes once):
  - `tint.addCorrection` (`tint_add_correction`): `{ target, at?, values?, limit?, name? }` adds a layer (default: the bottom of the stack) and returns `{ nodeId }`.
  - `tint.setCorrection` (`tint_set_correction`): `{ target, nodeId, patch: { values?, limit? (null removes), opacity?, on?, name? } }`; each given value field replaces that field whole.
  - `tint.removeNodes` (`tint_remove_nodes`): `{ target, nodeIds }`; consumers read the removed node's input, and its `grade.nodes.<id>.*` key tracks go with it.
  - `tint.moveLayer` (`tint_move_layer`): `{ target, nodeId, to }`.
  - `tint.reset` (`tint_reset`): `{ target, tools?, nodeId?, fields? }`; with none of `tools`, `nodeId` and `fields` the whole grade (and every `grade.*` track) goes; with `tools` only the fields those tools own (`logic/tools.ts`, `TOOL_FIELDS`) are cleared, keys included; `nodeId` limits that to one correction (all tools when none are given); `fields` names top-level value fields to clear beside the tools or alone, and a name that isn't a field of `DEFAULT_CORRECTION` fails with `tint.invalid_grade` before anything is written.
  - Read tools: `tint_scopes` (`{ at?, compositionId? }`: captures the graded frame with `captureAt` at `at` (default the agent's playhead in its open composition; pass `at` with another composition; no seek, the time measured comes back as `time`) and measures it with `scopeStats`: r, g, b `{ min, max, mean }` 0 to 255, `clipped.low/high` shares 0 to 1 of pixels at or under 1% / at or over 99% luma, `histogram` 16 luma buckets as shares, `skinDistance` mean degrees from the 123 degree skin line weighted by saturation), `tint_get_grade` (`{ target }`: the layers, numbers, and nodes with full values) and `tint_describe` (fields and defaults, ranges, tools, color spaces, looks, LUTs).
  - Failures: `tint.target_not_found`, `tint.not_gradeable`, `tint.node_not_found`, `tint.invalid_grade` (the `validateGrade` message; nothing is written), `tint.sealed` (a place inside a sealed card or a move the stack can't show), `tint.animated` (a static write to a field that has keys; the key path comes later).
- **View commands** (not undoable, not saved, no MCP tools: they are the user's view; `tint.view.commands.ts`): `tint.setMode` (`baby` | `leader`), `tint.pin` (`{ clipId | null }`: makes a gradeable clip of the open composition the one being graded and seeks into it, to where it was last viewed, else its middle; fails with `tint.clip_not_found`), `tint.selectNode`, `tint.setTool`, `tint.setLevel`.
- **Current clip** (`tint.current.ts`, `followCurrent`, registered in `setup` with `onDispose`): the pinned clip until the playhead leaves it (or it is deleted, or another composition opens), else the gradeable clip (`canGrade`, not disabled) under the playhead on the topmost video track that isn't hidden. It follows the playhead without React; `TintApi.current()` and `onCurrent(fn)` read it, and `viewedAt(clipId)` is where the playhead last was inside a clip. Clicking a card in the strip runs `tint.pin`; Ctrl, Cmd or Shift click goes through `TimelineApi.selectClip(id, true)`, so that selection is shared with Edit and shows on the card.
- **Points it owns:** none yet (`tintLooks` comes with looks)
- **API** (`TintApi`, per kernel): `thumb(clipId, nodeId, time, compositionId)` (a data URL of the clip alone with its grade cut at that node: `PreviewApi.captureAt(…, { only, filters: { "tint.cut": nodeId } })`: the cut is that one capture's own option, read by `tint.grade` as `info.options` (`TINT_CUT`), never shared state; queued one at a time), `live` (`TintLive`: `get(clipId)`, `set(clipId, LiveGrade | null)`, `subscribe(fn)`; values being dragged, by node (`Partial<CorrectionValues>`, `opacity`, `on`), laid over the saved grade by the filter; each `set` asks `preview.redraw()`; never in history), `available` (a getter: `PreviewApi.gpuAvailable()`, whether WebGL2 works; when false the page shows `TintUnavailable` instead of the page), `current()`, `onCurrent(fn)`, `viewedAt(clipId)`, `view` (`TintView`: the seal mode, the pinned clip, the open tool, the wheels mode, the grade level, the scope, the curve, the left tab, the selected layer, the Color mix family, and the viewer toggles; never in history)
- **Files:** `tint.current.ts` (`createCurrent`, `followCurrent`), `tint.view.commands.ts`, `tint.keys.ts`, `logic/strip.ts` (`stripClips`: every gradeable clip of the composition's video tracks by start, tagged `V1` (the top track) `V2`…; `clipUnder`, `holdsTime`, `landingTime`, `neighbourClip`), `tint.guards.ts`, `tint.node.commands.ts` (add, set, remove, move; `targetSchema`), `tint.commands.ts` (reset, `tintCommands`), `tint.mcp.ts`, `logic/tools.ts` (`TOOL_FIELDS`, `clearTools`); and
  - `tint.store.ts`: `createTintView()`, `createTintLive(redraw)`. `tint.filter.ts`: `createTintFilter(live)`, `TINT_GRADE_FILTER`. `tint.layout.ts`: `TINT_LAYOUT`, the page's sizes from the mockup. `tint.types.ts`: every type.
  - `logic/`: `graph.ts` (`nodeBox`, `inPort`, `outPort`, `GRAPH_ENDS`), `viewbox.ts` (`unitsPerPx`, `panView`, `zoomView`; the view stays between 260 and 4000 graph units wide), `wires.ts` (`wirePath`), `scopes.ts` (`luma`, `histogram`, `chroma`), `color/curves.ts` (`monotoneCurve`, Fritsch–Carlson, and `curvePath`).
  - `logic/` (the grade as layers, pure): `order.ts` (`topoOrder`, depth first from `out` so a chain reads top to bottom; `gradeGraph`, the nodes on a picture path from source to out; `postDominators`), `shape.ts` (`pairOf`: one step between a vertex and its immediate post-dominator, read as a layer, a side-by-side or stacked group, a per-channel group, or nothing), `seal.ts` (`parseStack`, `sealedRegions`), `stack.ts` (`toStack`, `numberOf`, `emptyGrade`), `stack.edit.ts` (`insertLayer`, `moveLayer`, `removeNodes`), `stack.group.ts` (`groupLayers`, `ungroup`), `rewire.ts` (ref rewiring and stack positions). Stack order: top is closest to the source; numbers `"01"`… in stack order, depth first, a sealed card's corrections included. A step that isn't a layer or a recognized group is **sealed**, and so are keys the stack can't show (a key join, a pick off the picture path, a pick from a sibling branch): the steps holding every correction of such a key are sealed together (`"sealed:<first node>"`). A shared key from a correction above is not sealed ("Uses the pick of 03"). Nodes off the picture path and not used as keys aren't shown. Every edit returns a new grade; `moveLayer` and `groupLayers` return null for what Baby Seal can't do (into or out of a sealed card, a group into itself, an invalid result). A list's last item exits with the ref its sink reads, channel included, so an edit there keeps a split's channel; a slot whose picture is a whole split (read through several channels) takes no edit. `ungroup` also points off-path readers of the join at the last branch's end, and readers of the split at the group's input.
  - `logic/color/` (the color math, the CPU reference; values are display-referred Rec.709, 0…1 in range, never clamped between steps): `basics.ts` (every constant the shader shares, the Rec.709 transfer, the log-ish space of contrast, `whiteBalance`, tone bands, rolloff; the formulas chosen are written at its top), `wheels.ts` (the primary wheels: a puck's reach toward each channel's hue, red at the top and clockwise, `y` down as `ColorWheel` draws it; `out = gain (in + lift (1 - in))^(1 / gamma) + offset`), `correct.ts` (`prepareCorrection`, what a correction's values come to for every pixel, the shader's uniforms; `applyCorrection`; `correctPixel`, in the spec's order: exposure and white balance, wheels, contrast, tone bands, rolloff, saturation, vibrance and hue with protect skin), `evaluate.ts` (`gradeChain`, `evaluatePixel`). `logic/live.ts`: `withLive(grade, live)`.
  - `render/`: `correct.glsl.ts` (`correctPass`: one program, `tint.correct`, for every correction, the GLSL of `correct.ts` line for line with the constants written in from `basics.ts`; it mixes the result over its input by opacity), `passes.ts` (`gradePasses(grade, live)`: one pass per correction that is on and shows, each reading the one before). **Chains only for now:** `gradeChain` walks back from `out`; a parallel or layer join follows its first input, a channel join its red one, a split its input (a channel draws as the whole picture), so a grade with joins draws one branch rather than failing. The CPU and the GPU agree within one 8-bit step (`docs/superpowers/specs/2026-11-03-tint-webgl-check.md`, Task 7).
  - `ui/TintPage.tsx`: layout D (sizes in `tint.layout.ts`: gutters 8, grade panel 372, Leader columns 1.15fr/1fr, clips 172, lower row 330, rail 52, header 38). Panels float on the table: `GradePanel` and `Viewer` on top (the grade panel widens in Leader Seal), `ClipStrip`, then `ToolsPanel` and `ScopesPanel`. `TintPanel` is the card with a header row; `PanelNote`, `HeaderGap`, `HeaderRule`, `InfoTip` fill headers. `view.hook.ts` (`useTintView`) and `view.set.hook.ts` (`useTintSet`) read and change `view`.
  - Grade: `GradePanel` (Layers or Nodes, Looks), `LayerList` (the current clip's `toStack`, `numberOf`, `LayersContext`) with `StackItems`, `LayerRow` (grip drag through `layer.drag.gesture.ts` and `logic/drop.ts`: DOM feedback, one `tint.moveLayer` on release, Escape cancels; eye = `on`; double-click renames; `OpacityScrub`: live value through `useLiveEdit` while dragging, one `tint.setCorrection` on release; Delete on a focused row = `tint.removeNodes`), `GroupRow`, `SealedCard` (wired in Leader Seal, values kept editable when expanded), `LayerChip` (`logic/layers.ts` `layerChip`), `LayerThumb` (fed by `thumbs.hook.ts` `useNodeThumbs`: 96 by 54, 400 ms after the last change, never while playing, nothing shown when a capture fails), `FlowLabel`, `AddMenu` (Correction, above the selected layer; groups and Look join later); every command goes through `layers.actions.hook.ts` (and `settle.ts`), which notify on a refusal; `NodeGraph` with `NodeBox` and `node.menu.ts` (right-click), moved by `graph.camera.ts` (`createGraphCamera`, through `graph.camera.hook.ts`: drag empty space or middle-drag to pan, wheel to scroll, Ctrl/Cmd + wheel to zoom at the pointer, double-click empty space or the Fit button to see it all; it writes the SVG's view box and the dot grid to the DOM, never React state); `looks/LooksTab`, `looks/LookCard`.
  - Viewer: `Viewer` (clean viewer fills the window, Esc leaves), `ViewerFrame` holds `PreviewStage bare` (the same stage the Sound page uses; only the newest mounted stage is drawn on), `ViewerTransport` (`Timecode`, `PlayButton`, previous/next clip with rich tips; Loop and Grab still aren't wired), `ViewerBar` (before/after and bypass drive the preview's `picture.setCompare(0.5 | null)` and `setBypass`, so the "Grades off" tag reads the real state and the preview's own wipe line is the divider; Shift+D runs the not-undoable `tint.setBypass` on this page; leaving the page runs `tint.clearViewing` (core's `followPageLeave`) so bypass and before/after don't outlive the viewer; color space, zoom, clean viewer; side by side, sample points, false color, clip warning and guides are hidden until the inspect tools are built), `FrameTag`, `FalseColorFilter` (an SVG stand-in), `FalseColorLegend`, `GuidesOverlay`, `SamplePoints`, and `ViewerTransport`.
  - Clips: `ClipStrip` (header actions still do nothing), `ClipCard` (poster, codec and rate from `media`: `probes` for the poster and `proxy.meta.fps`, `fileFacts` for the codec, read once; see `clip.info.hook.ts`), `TimelineOverview` (one row per video track, playhead through the DOM), hooks `strip.hook.ts` (`useStrip`) and `current.hook.ts` (`useCurrentClip`, `useCurrentEntry`), `CurrentNote`, `TintUnavailable`, `LevelSwitch` (this clip, shot group, whole timeline), `VersionMenu`, `PastePartMenu`.
  - Tools: `ToolsPanel`, `ToolRail`, `ToolHeader`; `tools/tools.registry.ts` (`TOOLS`: id, name, tip, key, icon, body) and one file per tool: `BasicsTool`, `WheelsTool` (with `ColorWheel`, `JogBar`, `wheel.gesture.ts`, `jog.gesture.ts`), `CurvesTool` (`CurveEditor`), `ColorMixTool`, `WarperTool` (`WarperGrid`), `CreativeTool`, `LimitTool` (`RangeBar`), `LutTool`, `MatchTool`, `MixerTool`; shared `ToolColumns`, `ToolColumn`, `DemoSliders`, `ToggleLine` (real when given `onChange`). Editing: `edit.target.hook.ts` `useEditTarget` (the selected layer if it is a correction, else the first, else none, with its values over the defaults), `live.edit.hook.ts` `useLiveEdit(clipId, nodeId)` (`preview(patch)` lays live values over the picture, `commit(patch)` sends one `tint.setCorrection`, or `tint.addCorrection` with those values when there is no correction yet, then drops the live values, `cancel()`, `rev` bumps on a refusal so controls keyed by it show the saved values again; nothing is previewed before the first correction exists), `tool.edit.hook.ts` `useToolEdit`, `tools/ValueSliders.tsx` (a `SliderField` per number with its `GRADE_RANGES` range and a double click on the label resetting to `DEFAULT_CORRECTION`; fields in `tools/basics.fields.ts`). A wheel's puck drag (`wheel.gesture.ts`, math in `logic/color/wheels.ts`: `wheelPuckAt`, `wheelColorNumbers`, `wheelWithChannel`) and the master jog bar move the puck, numbers and live values in the DOM only; one command on release, Escape cancels. The tool header's reset runs `tint.reset` on the selected correction only (`nodeId`) with what the page shows (`PAGE_RESET` in `logic/tools.ts`: Basics' fields; Wheels' fields plus its six sliders, passed as `fields`); disabled for tools not built yet. A commit that changes nothing is skipped (sliders) and `tint.setCorrection` / `tint.reset` write nothing when the grade comes out the same. The keyframe diamond and the One click buttons wait for their tasks.
  - Scopes: `scopes/ScopesPanel` (one effect per scope kind: sizes, theme token `--border` for the graticule, and `scopes.loop.ts` `startScopesLoop`, one animation-frame loop reading `picture.readFrame(256)` at most 15 Hz while playing and once after each drawn frame while paused; canvases are painted directly, no React state per frame), `scopes/ScopeCanvas`, `scopes/scope.draw.ts` (`createScopePainter`; trace colors are data colors); the binning is `logic/scopes.ts` (`scopeData`, `scopeStats`).
  - `ui/demo/`: the demo grade (`DEMO_NODES`, `DEMO_WIRES`, `DEMO_REGIONS`), looks, tool values, and the demo picture (`DEMO_FRAME`, for node previews and looks). Deleted once the grade lives in `project`.
- **Bit depth:** grading (being built, see the plan) works on 8-bit pictures, in the preview and in export, which is what the app decodes today. TODO: support 10-bit and 16-bit sources (camera log footage), at least for export, so heavy grades don't band. See the design's "Decisions after review".
- **Not yet:** log and zone wheels, curves, Color mix, the warper, skin pull, the mixer, Creative, LUTs, limits, joins and splits in the passes, the input color space, shot group and timeline grades; editing from the page for every tool but Basics and the primary wheels, keyed grade values (`tint.animated`) (the node graph and the other tools are still demo data); the viewer's false color, sample points, clip warning, guides and side by side, Loop, Grab still and the strip's copy and paste buttons do nothing yet. No Detail tab, shapes or tracking in v1.
