# sound

The Sound page, a tab between Edit and Export, and the mix of a composition: how each audio track and the master sound, with two mixes to switch between. The page has a transport row, the audio-only timeline over a panel (Clip and Loudness) and a small preview on the left, and the mixer on the right with Master pinned at its edge (layout B, `docs/prototype/designs/sound-page.html`). The values live in `project` (`Track.mix`, `Composition.mix`), since core modules read them; this module owns the page, the commands and the tools.

- **Tier:** feature
- **Requires:** `project`, `timeline` (the panel, `setTrackMuted`, `splitAt`, Snap), `preview` (the stage, play, the timecode, live mix, solo, monitor, meters, loudness), `inspector` (`ClipTabSections` in the Clip tab)
- **Contributes:** page `sound.page` (`SOUND_PAGE`; `appPages`, icon `AudioLines`, `keepsPlayback: true`, `timelineScope: "sound"`: playback goes on and Space, S and Delete work here, and the timeline edits sound only)
- **Points it owns:** —
- **API** (`SoundApi`, per kernel): `view` (`SoundViewState`: `selectedTrack`, `solo`, `expanded`, `monitor`; never in history), `selectTrack(trackId | null)`, `setExpanded(expanded)`. The commands are exported from `index.ts`.
- **Files:**
  - `sound.mix.commands.ts`: the mix commands below. Inputs are built from the schemas in `project` (`volumeDbSchema`, `panSchema`). `sound.guards.ts`: `audioTrack` (the audio track or `sound.track_not_found` / `sound.not_audio`), shared with the listening commands.
  - `sound.monitor.commands.ts`: `sound.setSolo`, `sound.setMonitor` and `sound.clearListening`. They write `view` and push the result to `preview.sound` (`setSolo`, `setMonitor`). Not undoable and no MCP tools: they act on the user's ears, like `settings.open`.
  - `sound.leave.ts`: `followSoundPageLeave(pages, onLeave)`. The module runs `sound.clearListening` each time the user leaves the Sound page: solo, Mono and Dim show nowhere else, so Edit never plays soloed or dimmed without saying so. The speaker volume stays, like a knob on the desk.
  - `sound.store.ts`: `createSoundView()`. `sound.mcp.ts`: the tools below.
  - `logic/meter.ts`: `meterHeight(db)` (0 at −60 dBFS, 1 at 0), `holdPeak(previous, now, at)` (the 1.5 s peak hold; the engine gives instantaneous peaks only), the colour thresholds (−6 and −1 dBFS), `formatDb`. `logic/fader.ts`: the fader taper (`faderPosition`, `faderDb`: −60 / −30 / −12 / 0 / +12 dB at 0 / ¼ / ½ / ¾ / 1, a tenth of a dB), `panPosition`, `panAt`, `formatPan`.
  - `ui/SoundPage.tsx`: the layout. `TimelinePanel scope="sound"` with a `focus` (the selected track, marked on its header), `SoundPanel` and `PreviewStage bare`, `MixerPanel`. Expand all hides the left column (kept mounted, so the timeline keeps its place). Only the open page is mounted, so the page's preview takes the frames only while it's open (`attachCanvas` draws on the newest stage) and the editor's gets them back when it closes, with the same engine: playback, the meters and the loudness go on across the switch.
  - `ui/SoundTransport.tsx`: `Timecode` and `PlayButton` (from `preview`); Cut (`timeline.splitAt` at the playhead, on the selection if any, like S); Snap (`timeline.setSnap("sound", …)`, the Sound timeline's own switch; Edit always snaps); `MixSwitch` (Mix A/B, `sound.switchMix`, the kit's `SegmentedControl`, active underlined in `--mark`); `MonitorControls` (Mono, Dim, the speaker `LineSlider`). `TransportTool`, `TransportSeparator`.
  - `ui/MixerPanel.tsx`: header (strip count, Expand all / Back to timeline), a `MixerStrip` per audio track of the open composition in `trackOrder` (`A1`…), scrolling sideways, or an `EmptyState`; `MasterStrip` pinned outside the scroller. It holds the page's one meter loop.
  - `ui/MixerStrip.tsx`: name, code, "Sends to Master" (plain text until buses), `PanSlider`, `Fader` with two `Meter`s, M (`timeline.setTrackMuted`), S (`sound.setSolo`). A click selects the track; a selected strip scrolls into view, and so does its header on the timeline. `StripToggle`, `StripLabel`.
  - `ui/Fader.tsx`, `ui/LineSlider.tsx` (pan, speaker), `ui/PanSlider.tsx`, `ui/slider.hook.ts` (`useSliderDrag`), `ui/fader.gesture.ts` (`startFaderDrag`): a drag writes the handle and readout with `style` and plays the value live (`preview.sound.previewMix`, or `setMonitor` for the speaker); the release sends one command when the value changed, then clears the live value and puts the handle where the document says (so a refused command shows). On the handle the drag is relative, elsewhere it jumps. Double-click returns to 0 dB / centre. No React state while dragging (rule 24). The level reads in `--mark` when it isn't 0 dB, the pan thumb when it isn't centred.
  - `ui/Meter.tsx`, `ui/meters.loop.ts` (`createMeterLoop`), `ui/meters.hook.ts` (`useMeterLoop`), `ui/meters.context.ts`: every meter side registers with one `requestAnimationFrame` loop that runs only while the timeline plays and the mixer is mounted; it reads `levels()` once a frame and writes each bar (`clip-path`) and hold line through the DOM, only where they changed. The bar is a gradient of `--on` up to −6 dBFS, `--foreground` to −1, `--mark` above; stopping empties them.
  - `ui/SoundPanel.tsx`: Clip (`ClipTabSections tab="audio"`: the inspector's Audio sections of the selected clip, with their key diamonds) and Loudness. Both stay mounted so the history goes on behind Clip. `PanelCard`.
  - `ui/LoudnessTab.tsx`, `ui/LoudnessHistory.tsx`, `ui/loudness.hook.ts` (`useLoudnessFeed`, 10 Hz): integrated, momentary, short term, true peak and range written through refs; Reset (`preview.sound.resetLoudness()`, and the history starts over); the short-term value of the last 60 s on a canvas, sampled while playing, drawn in `--border` and `--foreground` read from the canvas's style each time (a theme switch shows within 100 ms).
- **Invariants:** a mix equal to the default is never stored. Only audio tracks have a mix. Switching A and B swaps the live values (every audio track's mix, and the master) with `otherMix`; the first time, B starts as a copy of A, and tracks deleted since are left out. A switch is one undo step. Solo and the monitor live in this module's `view`, per kernel, and never reach the document, history or an export. Solo, Mono and Dim last only while the Sound page is open.

| Command                | MCP tool                | Notes                                                                                                    |
| ---------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------- |
| `sound.setTrackMix`    | `sound_set_track_mix`   | `volumeDb` (-60 to 12) and `pan` (-1 to 1) of an audio track. `sound.not_audio`, `sound.track_not_found` |
| `sound.resetTrackMix`  | `sound_reset_track_mix` | Back to 0 dB and centre. `sound.not_audio`, `sound.track_not_found`                                      |
| `sound.setMaster`      | `sound_set_master`      | `volumeDb` of a composition (default: the actor's open one). `composition.not_found`                     |
| `sound.switchMix`      | `sound_switch_mix`      | To `"a"` or `"b"`; to the active one does nothing. `composition.not_found`                               |
| `sound.setSolo`        | —                       | `{ trackId, on }`. Not undoable. `sound.not_audio`, `sound.track_not_found`                              |
| `sound.setMonitor`     | —                       | `mono`, `dim`, `speakerDb` (-60 to 12), any of them. Not undoable                                        |
| `sound.clearListening` | —                       | No solo, Mono and Dim off; the speaker stays. Not undoable. Run on leaving the page                      |
| —                      | `sound_get_levels`      | Peaks per audio track and master (dBFS, null for silence) and the loudness; a message when nothing plays |
