# keyframe

Keys on a clip's values over time: add a key, move keys together, change their values, remove them, clear a field. The keys themselves are `Clip.animation` in `project` (read by the preview and export as data); this module owns the edit commands and tools. The inspector's diamonds and the timeline's Normal / Keyframes / Curves switch with its panel are here; the motion path on the canvas is here too.

- **Tier:** feature
- **Requires:** `project`, `element`, `preview` (the playhead, `preview.seek`), `inspector` (`fieldActions`), `timeline` (`timelineTools`, `timelineDocks`, `clipActions`, the header width)
- **Contributes:** overlay `keyframe.motionPath` (`previewOverlays`), field action `keyframe.key` (`fieldActions`, order 10, for every keyable field), key target `element` (`keyTargets`): every number, color, enum and boolean field of a clip's element, from `element`'s `keyableFields`; tool `keyframe.mode` (`timelineTools`, order 0: the switch), dock `keyframe.panel` (`timelineDocks`), clip badge `keyframe.badge` (`clipActions`), keybindings `keyframe.toggle-mode` (K) and `keyframe.ease-selected` (F9: Ease on the selected keys, ignored with none)
- **Points it owns:** `keyTargets` (this module for the element's fields; a module that keys values of its own, like speed, adds a target)
- **API** (`useModule(keyframeRef)` / `ctx.require(keyframeRef)`): `fieldsOf(clip)`, `fieldOf(clip, path)`, `clipboard` (what each actor copied, per kernel, never in history), `view` (the panel's state: mode, scope, selection, ... per kernel, never in history)
- **Files:**
  - `keyframe.view.commands.ts`: `toggleMode`. `keyframe.layout.ts`: `PANEL_HEADER_WIDTH`, `ROW_HEIGHT`, `GROUP_HEIGHT`, `MIN_PANEL_HEIGHT`. `logic/motion.ts`: `motionPath`. `logic/range.ts`: `keysInWindow`, `pagesSpan`, `summaryTimes`. `logic/graph.ts`: `valueScale`, `withScales`, `keyPoint`, `keyBoxes`, `dragPreview`, `curveSources`, `dragKeys`. `logic/handles.ts`: `handlePoints`, `alignedEase`, `handleSpots`, `handleEases`, `handleDrag`, `withEases`, `smoothChanges`, `allSmooth`. `CURVE_COLORS`, `CURVE_PADDING`, `CURVE_KEY_RADIUS` in the layout file. `ui/`: the panel's parts.
  - `keyframe.fields.ts`: the element target and the API. `keyframe.guards.ts`: `requireKey`, `requireClip`, `requireField`, `checkKeyValue`, the Zod schemas.
  - `keyframe.ease.commands.ts`: setEase, setAfter, scale. `keyframe.clipboard.commands.ts`: copy, paste.
  - `keyframe.edit.commands.ts`: set, remove, move, setValues. `keyframe.commands.ts`: clear and the list. `keyframe.write.ts`: writes the tracks of a command in one `ctx.mutate`, then the static values and the targets' `afterWrite`.
  - `keyframe.view.store.ts`: the view store, and `pruneSelection`, which the module runs on every project change so the selection forgets keys that an undo or an agent removed.
- **Invariants:** a track never has zero keys: when the last key goes the track goes and its value becomes the static value (`KeyField.commitStatic`, run in the same command, so one undo step). A command validates every key and value before it writes, so one key that is gone (`keyframe.not_found`) changes nothing. `at` and `delta` are timeline times; stored key times are content times (`contentTime`, `timeOfContent`). A key set outside the clip lands on its nearest frame. A new track copies `blend`, `shared`, `min` and `max` from its field.
- **Clipboard:** copied keys store content-time offsets from the earliest key, with value, ease and smooth. A paste puts the earliest at `at` and keeps the spacing on the target clip's own clock, with fresh ids; paths the clip can't key are skipped.
- **Diamonds** (`ui/KeyAction.tsx`): a previous arrow, a diamond and a next arrow at the end of a row, for the row's paths that the clip can key (Position keys X and Y, a color its opacity). The diamond adds keys at the playhead (`keyframe.setMany`, one step) or removes the ones there (`keyframe.remove`, one step); the arrows `preview.seek` to the nearest key time of any of the paths. It subscribes to `playback.onTime` and sets `data-state` on itself and `data-key-state` on the row (no React state), which colors the diamond and the value.
- **The switch and the panel** (`ui/ModeSwitch.tsx`, `ui/KeyPanel.tsx`): `keyframe.toggleMode` (`mode?`: `normal`, `keys` or `curves`; without it K flips between Normal and the last view; not undoable, no tool, since it only moves the user's view) sets `view.mode`/`last`, the timeline's header width (`PANEL_HEADER_WIDTH` = 262 while open, back to the default in Normal) and, going to Normal, clears `maximized` and shows the tracks. `KeyPanel` draws nothing in Normal; otherwise it is a dock with a divider (the height is set in the DOM while dragging and written to `view.panelHeight` on release), `PanelToolbar` (Showing: selected clips / all animated, Add key at playhead on the primary row, Maximize / Restore tracks through `setTracksHidden`), and one vertically scrolling box of `ClipGroup`s: a fold arrow, the name and a summary band (a grey diamond for each distinct key time), then a `PropertyRow` per animated field (swatch, name, value at the playhead, and the same previous / diamond / next as the inspector: `KeyControls` in `ui/KeyAction.tsx`) with its `KeyBand`. `usePanelRows` lists the clips (the timeline selection, partners included, or every clip of the open composition with scope `all`; only clips with keys). Keys sit at `timeToPx` on the timeline's own scale; `usePanelScroll` sets `--panel-scroll` on the panel from `timeline.onScroll` (the bands shift by it) and forwards the wheel (sideways or Shift scrolls, Ctrl zooms around the pointer), and `usePanelWindow` gives the page span (the view's page and one on each side) so a band draws only `keysInWindow` of it (rule 26). `PanelPlayhead` moves from the clock without renders. In Curves the rows keep only their headers (a fixed column) and `CurveGraph` takes the rest. A click on a row (not on its diamond or arrows) makes it primary and shows or hides its curve in `view.shown` (the swatch is lit when shown); a step or color row never goes into `shown`. With `shown` empty the graph draws the primary row, or the first number row, without writing the store.
- **Diamonds** (`ui/KeyDiamond.tsx`): rotated squares; square for a stepped track, rounded for an eased key, red when selected, 40% for a key past the clip's ends. Each carries `data-key-ref="clipId|path|keyId"`, a summary one carries `data-key-summary="clipId|time"` instead.
- **On the clips** (`ui/ClipBadge.tsx`): a selected clip with keys gets an arrow (opens the last view, or goes back to Normal) and, in Normal, a small diamond for each key time on its bottom edge.
- **View state** is the module's `view` store, never in history: fold, scope, the primary row and the divider are set straight on it by the panel, like the library's.
- **Selecting and moving** (`ui/panel.keys.hook.ts`, `ui/key.gesture.ts`, `ui/box.gesture.ts`, `logic/moves.ts`, `logic/picking.ts`): one `pointerdown` listener on the panel. A click on a diamond selects it, Ctrl/Shift toggles, a summary diamond selects every key of its clip at that time, a press on empty band draws a rubber band (`border-primary bg-primary-soft/40`) and picks diamonds by their centers on release (a click clears). Pressing a selected key drags the whole selection: `clampDelta` keeps keys that start inside their clip inside (keys already outside don't limit), the diamonds (found once at the start) slide with `transform`, and release sends one `keyframe.move`; Escape cancels. Any press in the panel sets `view.focused`, a press elsewhere clears it; while focused with keys selected, a capture-phase `keydown` (skipping text fields) takes Delete / Backspace (`keyframe.remove`), Ctrl+C (`keyframe.copy`) and Ctrl+V (`keyframe.paste` onto the timeline's selected clips at the playhead) before the app's shortcuts. The toolbar adds Copy, Paste, Select all keys and Fit (`ui/panel.actions.hook.ts`: zooms to the listed clips' span).
- **The graph** (`ui/CurveGraph.tsx`, `ui/curve.pointer.hook.ts`, `ui/curve.draw.ts`, `ui/curve.gesture.ts`, `logic/graph.ts`): one canvas for every shown curve of the listed rows. `valueScale(track, clip, height, padding)` samples the clip's span so an overshoot fits and gives `toY` / `toValue` / `low` / `high`, one scale per curve. `drawCurves(ctx, scene)` paints a grid (at least 48 px apart), the center line, each curve in its `CURVE_COLORS` token by row order (read with `getComputedStyle` once per draw), sampled once per 2 px of the visible window only, the primary stronger with its `high` and `low` at the left, and the keys as diamonds (red when selected). Tracks with `blend` `step` or `color` draw no curve; their rows stay. The canvas is scaled by the device pixel ratio and redrawn in an animation frame when the rows, `shown`, `primary`, the selection, the project, the zoom, the scroll or the size change, never per playback frame (the playhead is `PanelPlayhead` over it). A press on a key selects it (Ctrl/Shift toggles, through `toggled`), a press on empty plane draws the rubber band (`keysInBox`), and dragging selected keys of shown curves moves them in time (`clampDelta`) and value (each by its own scale, frozen at the start; Shift keeps the larger axis) with the curve redrawn each frame from a preview track (`dragPreview`). On release one `keyframe.move` carries `delta` and each changed key's `value`, clamped to the track's `min` / `max`; Escape cancels.
- **Handles** (`logic/handles.ts`, `ui/handle.gesture.ts`, drawn by `ui/curve.draw.ts`, hit first in `ui/curve.pointer.hook.ts`): the primary curve's selected keys show round handles (`CURVE_HANDLE_RADIUS`) on a `bezier` segment on either side. The handle on the left of a key edits the previous key's ease (`x2, y2`), the one on the right its own (`x1, y1`). A `linear` segment shows none until Smooth handles or a preset makes it `bezier`; `named` and `hold` never do. A press on a handle drags it: x is clamped between the two keys, y is free (so it can overshoot; a segment with no value change only moves in x), the curve is redrawn each frame from `withEases` on the scales the drag began with, and release sends one `keyframe.setEase` with the one or two changed segments; Escape cancels. On a `smooth` key with a bezier on both sides, `alignedEase` turns the other side's handle onto the same line in real units (it keeps its reach in time and takes the moved handle's slope, value per time; it stays as it was when the slope can't be had: a flat or vertical handle, or a segment with no value change).
- **The strip** (`ui/PresetStrip.tsx`, `ui/EaseThumb.tsx`): its own row at the bottom of the panel in Keyframes and Curves (not in Normal), inside the panel's height (`PRESET_STRIP_HEIGHT`; the panel's minimum height grew with it). Each preset in `EASE_PRESETS` order is an `EaseThumb` (40 samples of `easeProgress`) with its label; a click sends one `keyframe.setEase` for every selected key. The preset all selected keys share takes `border-mark`; Custom (dashed, not clickable) is marked when they all share a curve `presetOf` calls `custom`, and nothing is marked when they differ. The toolbar's **Smooth handles** turns the selected number keys' `linear` segments on both sides into the bezier that moves the same (`LINEAR_BEZIER`, `1/3, 1/3, 2/3, 2/3`) and sets `smooth`; when every selected key is already smooth it clears `smooth` and leaves the curves. That bezier is not a preset, so `presetOf` says Custom for it.
- **The motion path** (`ui/MotionPath.tsx`, `ui/motion.gesture.ts`, `logic/motion.ts`): a `previewOverlays` entry, shown while the panel is open (not Normal), the toolbar's **Motion path** switch (`view.motionPath`, default on) is on, and exactly one selected clip has a `transform.x` or `transform.y` track. `motionPath(clip, format, samples)` samples the clip's span (120 points) through `trackValue`, an axis without a track using the clip's static value, and gives a diamond for each distinct key time with the keys there, in output pixels from the frame's center; the overlay turns them into % of the frame (SVG `viewBox` of the format, dashed `stroke-primary`, `vector-effect: non-scaling-stroke`). DOM only, so never in a capture or export. Only the diamonds take pointer events. Dragging one moves it in the DOM; release sends one `keyframe.setValues` with an `offset` for each key at that time (an axis with no key there is dropped); Escape cancels, a failed command puts the diamond back and notifies. The path itself redraws when the project changes, not during the drag.
- **Not yet:** snapping and frames while dragging.

| Command               | MCP tool              | Notes                                                                                                                                                                               |
| --------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `keyframe.set`        | `keyframe_set`        | Adds or updates the key on that frame; `value` defaults to the value there. `clip_not_found`, `not_keyable`, `invalid_value`. Returns `key`                                         |
| `keyframe.setMany`    | `keyframe_set_many`   | Keys several fields of a clip at `at` with their current values, in one step; any path that can't be keyed changes nothing. `clip_not_found`, `not_keyable`. Returns `keys` by path |
| `keyframe.remove`     | `keyframe_remove`     | The last key of a field leaves its value as the static value. `not_found`                                                                                                           |
| `keyframe.move`       | `keyframe_move`       | Keys move together by `delta`, so moved keys never land on each other; one that lands on an unmoved key replaces it. `not_found`, `invalid_value`                                   |
| `keyframe.setValues`  | `keyframe_set_values` | A `value`, or an `offset` clamped to the field's range. `not_found`, `invalid_value`                                                                                                |
| `keyframe.clear`      | `keyframe_clear`      | Removes tracks; the value at `at` becomes the static value. `clip_not_found`, `not_keyable`                                                                                         |
| `keyframe.setEase`    | `keyframe_set_ease`   | Per key `ease` (preset name or ease object) and/or `smooth`. `not_found`, `invalid_value`                                                                                           |
| `keyframe.setAfter`   | `keyframe_set_after`  | `hold` / `loop` / `pingpong` after the last key. `not_found`, `no_loop` (speed)                                                                                                     |
| `keyframe.scale`      | `keyframe_scale`      | Distance from `pivot` times `factor` (not 0), rounded. A negative factor flips the keys and mirrors the curves. `not_found`, `invalid_value`                                        |
| `keyframe.copy`       | `keyframe_copy`       | Not undoable; to your own clipboard. `not_found`                                                                                                                                    |
| `keyframe.paste`      | `keyframe_paste`      | Earliest copied key at `at`, onto each clip's matching fields. `clipboard_empty`, `clip_not_found`, `no_target`                                                                     |
| `keyframe.toggleMode` | (none)                | The user's view; not undoable                                                                                                                                                       |
| (read)                | `keyframe_sample`     | `{ time, value }[]` of a field from `from` to `to` by `step`, at most 1000. Works without keys                                                                                      |
| (read)                | `keyframe_list_eases` | The ease presets, in order                                                                                                                                                          |
