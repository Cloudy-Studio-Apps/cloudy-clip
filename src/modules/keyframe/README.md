# keyframe

Keys on a clip's values over time: add a key, move keys together, change their values, remove them, clear a field. The keys themselves are `Clip.animation` in `project` (read by the preview and export as data); this module owns the edit commands and tools. The inspector's diamonds and the timeline's Normal / Keyframes / Curves switch with its panel are here; the canvas parts come later.

- **Tier:** feature
- **Requires:** `project`, `element`, `preview` (the playhead, `preview.seek`), `inspector` (`fieldActions`), `timeline` (`timelineTools`, `timelineDocks`, `clipActions`, the header width)
- **Contributes:** field action `keyframe.key` (`fieldActions`, order 10, for every keyable field), key target `element` (`keyTargets`): every number, color, enum and boolean field of a clip's element, from `element`'s `keyableFields`; tool `keyframe.mode` (`timelineTools`, order 0: the switch), dock `keyframe.panel` (`timelineDocks`), clip badge `keyframe.badge` (`clipActions`), keybinding `keyframe.toggle-mode` (K)
- **Points it owns:** `keyTargets` (this module for the element's fields; a module that keys values of its own, like speed, adds a target)
- **API** (`useModule(keyframeRef)` / `ctx.require(keyframeRef)`): `fieldsOf(clip)`, `fieldOf(clip, path)`, `clipboard` (what each actor copied, per kernel, never in history), `view` (the panel's state: mode, scope, selection, ... per kernel, never in history)
- **Files:**
  - `keyframe.view.commands.ts`: `toggleMode`. `keyframe.layout.ts`: `PANEL_HEADER_WIDTH`, `ROW_HEIGHT`, `GROUP_HEIGHT`, `MIN_PANEL_HEIGHT`. `logic/range.ts`: `keysInWindow`, `pagesSpan`, `summaryTimes`. `ui/`: the panel's parts.
  - `keyframe.fields.ts`: the element target and the API. `keyframe.guards.ts`: `requireKey`, `requireClip`, `requireField`, `checkKeyValue`, the Zod schemas.
  - `keyframe.ease.commands.ts`: setEase, setAfter, scale. `keyframe.clipboard.commands.ts`: copy, paste.
  - `keyframe.edit.commands.ts`: set, remove, move, setValues. `keyframe.commands.ts`: clear and the list. `keyframe.write.ts`: writes the tracks of a command in one `ctx.mutate`, then the static values and the targets' `afterWrite`.
  - `keyframe.view.store.ts`: the view store, and `pruneSelection`, which the module runs on every project change so the selection forgets keys that an undo or an agent removed.
- **Invariants:** a track never has zero keys: when the last key goes the track goes and its value becomes the static value (`KeyField.commitStatic`, run in the same command, so one undo step). A command validates every key and value before it writes, so one key that is gone (`keyframe.not_found`) changes nothing. `at` and `delta` are timeline times; stored key times are content times (`contentTime`, `timeOfContent`). A key set outside the clip lands on its nearest frame. A new track copies `blend`, `shared`, `min` and `max` from its field.
- **Clipboard:** copied keys store content-time offsets from the earliest key, with value, ease and smooth. A paste puts the earliest at `at` and keeps the spacing on the target clip's own clock, with fresh ids; paths the clip can't key are skipped.
- **Diamonds** (`ui/KeyAction.tsx`): a previous arrow, a diamond and a next arrow at the end of a row, for the row's paths that the clip can key (Position keys X and Y, a color its opacity). The diamond adds keys at the playhead (`keyframe.setMany`, one step) or removes the ones there (`keyframe.remove`, one step); the arrows `preview.seek` to the nearest key time of any of the paths. It subscribes to `playback.onTime` and sets `data-state` on itself and `data-key-state` on the row (no React state), which colors the diamond and the value.
- **The switch and the panel** (`ui/ModeSwitch.tsx`, `ui/KeyPanel.tsx`): `keyframe.toggleMode` (`mode?`: `normal`, `keys` or `curves`; without it K flips between Normal and the last view; not undoable, no tool, since it only moves the user's view) sets `view.mode`/`last`, the timeline's header width (`PANEL_HEADER_WIDTH` = 262 while open, back to the default in Normal) and, going to Normal, clears `maximized` and shows the tracks. `KeyPanel` draws nothing in Normal; otherwise it is a dock with a divider (the height is set in the DOM while dragging and written to `view.panelHeight` on release), `PanelToolbar` (Showing: selected clips / all animated, Add key at playhead on the primary row, Maximize / Restore tracks through `setTracksHidden`), and one vertically scrolling box of `ClipGroup`s: a fold arrow, the name and a summary band (a grey diamond for each distinct key time), then a `PropertyRow` per animated field (swatch, name, value at the playhead, and the same previous / diamond / next as the inspector: `KeyControls` in `ui/KeyAction.tsx`) with its `KeyBand`. `usePanelRows` lists the clips (the timeline selection, partners included, or every clip of the open composition with scope `all`; only clips with keys). Keys sit at `timeToPx` on the timeline's own scale; `usePanelScroll` sets `--panel-scroll` on the panel from `timeline.onScroll` (the bands shift by it) and forwards the wheel (sideways or Shift scrolls, Ctrl zooms around the pointer), and `usePanelWindow` gives the page span (the view's page and one on each side) so a band draws only `keysInWindow` of it (rule 26). `PanelPlayhead` moves from the clock without renders. Curves shows the same rows for now.
- **Diamonds** (`ui/KeyDiamond.tsx`): rotated squares; square for a stepped track, rounded for an eased key, red when selected, 40% for a key past the clip's ends. Each carries `data-key-ref="clipId|path|keyId"`, a summary one carries `data-key-summary="clipId|time"` instead.
- **On the clips** (`ui/ClipBadge.tsx`): a selected clip with keys gets an arrow (opens the last view, or goes back to Normal) and, in Normal, a small diamond for each key time on its bottom edge.
- **View state** is the module's `view` store, never in history: fold, scope, the primary row and the divider are set straight on it by the panel, like the library's.
- **Selecting and moving** (`ui/panel.keys.hook.ts`, `ui/key.gesture.ts`, `ui/box.gesture.ts`, `logic/moves.ts`, `logic/picking.ts`): one `pointerdown` listener on the panel. A click on a diamond selects it, Ctrl/Shift toggles, a summary diamond selects every key of its clip at that time, a press on empty band draws a rubber band (`border-primary bg-primary-soft/40`) and picks diamonds by their centers on release (a click clears). Pressing a selected key drags the whole selection: `clampDelta` keeps keys that start inside their clip inside (keys already outside don't limit), the diamonds (found once at the start) slide with `transform`, and release sends one `keyframe.move`; Escape cancels. Any press in the panel sets `view.focused`, a press elsewhere clears it; while focused with keys selected, a capture-phase `keydown` (skipping text fields) takes Delete / Backspace (`keyframe.remove`), Ctrl+C (`keyframe.copy`) and Ctrl+V (`keyframe.paste` onto the timeline's selected clips at the playhead) before the app's shortcuts. The toolbar adds Copy, Paste, Select all keys and Fit (`ui/panel.actions.hook.ts`: zooms to the listed clips' span).
- **Not yet:** snapping and frames while dragging, the curves graph, motion path.

| Command               | MCP tool              | Notes                                                                                                                                                                               |
| --------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `keyframe.set`        | `keyframe_set`        | Adds or updates the key on that frame; `value` defaults to the value there. `clip_not_found`, `not_keyable`, `invalid_value`. Returns `key`                                         |
| `keyframe.setMany`    | `keyframe_set_many`   | Keys several fields of a clip at `at` with their current values, in one step; any path that can't be keyed changes nothing. `clip_not_found`, `not_keyable`. Returns `keys` by path |
| `keyframe.remove`     | `keyframe_remove`     | The last key of a field leaves its value as the static value. `not_found`                                                                                                           |
| `keyframe.move`       | `keyframe_move`       | Keys move together by `delta`, so moved keys never land on each other; one that lands on an unmoved key replaces it. `not_found`, `invalid_value`                                   |
| `keyframe.setValues`  | `keyframe_set_values` | A `value`, or an `offset` clamped to the field's range. `not_found`, `invalid_value`                                                                                                |
| `keyframe.clear`      | `keyframe_clear`      | Removes tracks; the value at `at` becomes the static value. `clip_not_found`, `not_keyable`                                                                                         |
| `keyframe.setEase`    | `keyframe_set_ease`   | Per key `ease` (preset name or ease object) and/or `smooth`. `not_found`, `invalid_value`                                                                                           |
| `keyframe.setAfter`   | `keyframe_set_after`  | `hold` / `loop` / `pingpong` after the last key. `not_found`, `no_loop` (speed)                                                                                                     |
| `keyframe.scale`      | `keyframe_scale`      | Distance from `pivot` times `factor` (not 0), rounded. A negative factor flips the keys and mirrors the curves. `not_found`, `invalid_value`                                        |
| `keyframe.copy`       | `keyframe_copy`       | Not undoable; to your own clipboard. `not_found`                                                                                                                                    |
| `keyframe.paste`      | `keyframe_paste`      | Earliest copied key at `at`, onto each clip's matching fields. `clipboard_empty`, `clip_not_found`, `no_target`                                                                     |
| `keyframe.toggleMode` | (none)                | The user's view; not undoable                                                                                                                                                       |
| (read)                | `keyframe_sample`     | `{ time, value }[]` of a field from `from` to `to` by `step`, at most 1000. Works without keys                                                                                      |
| (read)                | `keyframe_list_eases` | The ease presets, in order                                                                                                                                                          |
