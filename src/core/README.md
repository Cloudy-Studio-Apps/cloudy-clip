# core

The kernel. Modules and (later) plugins import it only through `@/core`.

| Piece                    | Where                             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------ | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Command bus              | `command/`                        | Validates (Zod), serializes, runs, rolls back on throw, times out at 30 s, never throws. `CommandInputs` maps ids to inputs (modules extend it), `PanelCommandId` = ids taking `clipIds`.                                                                                                                                                                                                                                                  |
| History                  | `history/`                        | One undo/redo log of Immer patches, tagged with origin and actor. Each actor undoes their own steps once `scopeUndo` is on. A step is reverted past others' newer steps by writing field values (`StorePolicy` on the store), refused with `history.conflict` when someone touched the same field or the document would be invalid. A policy's optional `settle` runs inside every change, so derived values are written in the same step. |
| Patchable stores         | `store/`                          | Zustand stores whose changes are recorded as patches. Changed only via `ctx.mutate`, or replaced whole via `ctx.replace` (only in a non-undoable command: it validates with the store's policy, refuses with `store.invalid`, and clears history).                                                                                                                                                                                         |
| Module host              | `module/`                         | `defineModule`/`defineModuleRef`; orders by `requires`/`after`, runs `setup` per kernel, `require(ref)`, `onDispose`; failures isolated (cleanups run), dependents skipped.                                                                                                                                                                                                                                                                |
| Points                   | `module/points.ts`                | `definePoint`; per-kernel registry of contributions (keyed points reject duplicates).                                                                                                                                                                                                                                                                                                                                                      |
| Shell points             | `shell/`                          | `layoutPanels`, `keybindings`, `topBarItems`, `appOverlays`, `matchKeybinding`: what the app shell renders and runs. Side panels show as rail tabs (`title`, `icon`).                                                                                                                                                                                                                                                                      |
| MCP                      | `mcp/`                            | Tool registry, `commandTool` helper, bridge to the native server. Each call carries its `McpCaller`; the bridge gives tools a bus that runs as that caller, and an `McpObserver` (`ctx.mcp.observe`) can refuse calls, name their undo steps and add notes to the reply.                                                                                                                                                                   |
| Errors                   | `errors/`                         | `Result`, `CommandFailure`, scoped logger, panel `ErrorBoundary`.                                                                                                                                                                                                                                                                                                                                                                          |
| React                    | `react/`                          | `KernelProvider`, `useKernel`, `useModule(ref)`, `usePoint(point)`, `useHistory`.                                                                                                                                                                                                                                                                                                                                                          |
| Time, ids, notifications | `time/`, `ids/`, `notifications/` | `Micros` helpers, readable ids, toasts.                                                                                                                                                                                                                                                                                                                                                                                                    |

Built-in `history` module (`historyRef`, core): commands `history.undo`, `history.redo` (act for the caller), `history.undoFor` (the user reverts a collaborator's step); MCP tools `history_undo`, `history_redo`, `history_list`; keybindings Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y.

**Pages.** `appPages` (`{ id, label, icon, group?, order?, component? }`) are the pages of the app, each with a tab in the top bar: Media, Edit, Sound | Export. A module or plugin adds one with `contribute(appPages, …)`. `group` names an `appPageGroups` entry (`{ id, order? }`), and a divider separates groups: `PAGE_GROUP_CREATE` is the default and `PAGE_GROUP_DELIVER` holds Export. A page may contribute its own group; one nobody declared comes last. `groupPages` puts them in tab order. Orders leave gaps (10, 20, 30), so a page can go between two others. The built-in `pages` module holds which one shows (`pagesRef`, `store`), contributes the two groups and the Edit tab (`EDITOR_PAGE`, the one page with no `component`), and the `pages.show` command changes it. The editor stays mounted under a page, playback pauses when you leave it, and plain keys (Space, S, Delete) only work on the editor.

`appMenuItems` holds the entries of the app's menu, behind the logo. An entry names its submenu (`menu`), and a `keybinding` gives it its shortcut and, without `run`, what it does, so a menu entry and its key can't drift apart. The shell adds a Go to submenu from `appPages`.
