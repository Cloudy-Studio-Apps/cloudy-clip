# core

The kernel. Modules and (later) plugins import it only through `@/core`.

| Piece                    | Where                             | What it does                                                                                                                                                                                                                                                                                                                        |
| ------------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Command bus              | `command/`                        | Validates (Zod), serializes, runs, rolls back on throw, times out at 30 s, never throws. `CommandInputs` maps ids to inputs (modules extend it), `PanelCommandId` = ids taking `clipIds`.                                                                                                                                           |
| History                  | `history/`                        | One undo/redo log of Immer patches, tagged with origin and actor. Each actor undoes their own steps once `scopeUndo` is on. A step is reverted past others' newer steps by writing field values (`StorePolicy` on the store), refused with `history.conflict` when someone touched the same field or the document would be invalid. |
| Patchable stores         | `store/`                          | Zustand stores whose changes are recorded as patches. Changed only via `ctx.mutate`.                                                                                                                                                                                                                                                |
| Module host              | `module/`                         | `defineModule`/`defineModuleRef`; orders by `requires`/`after`, runs `setup` per kernel, `require(ref)`, `onDispose`; failures isolated (cleanups run), dependents skipped.                                                                                                                                                         |
| Points                   | `module/points.ts`                | `definePoint`; per-kernel registry of contributions (keyed points reject duplicates).                                                                                                                                                                                                                                               |
| Shell points             | `shell/`                          | `layoutPanels`, `keybindings`, `topBarItems`, `appOverlays`, `matchKeybinding`: what the app shell renders and runs. Side panels show as rail tabs (`title`, `icon`).                                                                                                                                                               |
| MCP                      | `mcp/`                            | Tool registry, `commandTool` helper, bridge to the native server. Each call carries its `McpCaller`; the bridge gives tools a bus that runs as that caller, and an `McpObserver` (`ctx.mcp.observe`) can refuse calls, name their undo steps and add notes to the reply.                                                            |
| Errors                   | `errors/`                         | `Result`, `CommandFailure`, scoped logger, panel `ErrorBoundary`.                                                                                                                                                                                                                                                                   |
| React                    | `react/`                          | `KernelProvider`, `useKernel`, `useModule(ref)`, `usePoint(point)`, `useHistory`.                                                                                                                                                                                                                                                   |
| Time, ids, notifications | `time/`, `ids/`, `notifications/` | `Micros` helpers, readable ids, toasts.                                                                                                                                                                                                                                                                                             |

Built-in `history` module (`historyRef`, core): commands `history.undo`, `history.redo` (act for the caller), `history.undoFor` (the user reverts a collaborator's step); MCP tools `history_undo`, `history_redo`, `history_list`; keybindings Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y.
